# AutoCAD Coordinate Exporter

[English](README.md) | [Русский](README.ru.md)

**Обзор проекта:** https://ekatmoz88-alt.github.io/autocad-coordinate-exporter/

Документационная страница проекта экспорта текстовых меток AutoCAD и их координат WCS в CSV.

## Назначение

Предполагаемый рабочий сценарий состоит из трёх этапов: выбор текстовых объектов в чертеже, получение мировых координат WCS и формирование табличного CSV-результата для дальнейшей обработки.

## Пример данных

Опубликованная страница показывает иллюстративную структуру CSV. Значения в примере демонстрационные и не являются результатом фактического запуска скрипта.

## Текущие ограничения репозитория

В репозитории доступны README и обзорная HTML-страница. Исходный AutoLISP-файл и проверенный результат выполнения пока не представлены. Поэтому не заявляются конкретные команды запуска, API-функции или подтверждённая реализация экспорта.
