# Экспорт координат подписей из AutoCAD

Файл `coord-text-export.lsp` добавляет команду `TXTCOORD`. Она сохраняет
выбранные объекты `TEXT` и `MTEXT` в CSV-файл с разделителем `;`.

## Запуск

1. В AutoCAD загрузите `coord-text-export.lsp` командой `_APPLOAD`.
2. Запустите команду `TXTCOORD`.
3. Выберите подписи `TEXT` и/или `MTEXT`, затем нажмите Enter.
4. Укажите точность координат (по умолчанию — 3 знака после запятой).
5. Выберите путь для сохранения CSV-файла.

В файле будут столбцы `X;Y;Text`. Координаты берутся из точки вставки текста
и преобразуются в мировую систему координат WCS. Для `MTEXT` обычные коды
форматирования удаляются, переносы строк заменяются пробелами, а дроби
сохраняются в виде `числитель/знаменатель`. Текстовые значения заключаются
в кавычки, а кавычки внутри текста экранируются по правилам CSV.
