01 / Workflow

Простой путь к табличным данным

Назначение инструмента — вынести атрибуты выбранных текстовых объектов из чертежа в удобный для дальнейшей обработки CSV-файл.

STEP 01

Выбрать объекты

Отметить в чертеже текстовые метки, координаты которых нужно получить.

STEP 02

Получить WCS

Использовать мировые координаты выбранных объектов как пространственную основу выгрузки.

STEP 03

Экспортировать CSV

Сформировать табличный результат для просмотра и последующей обработки.

03 / Project scope

Назначение и границы

AUTOMATION

Меньше ручного переноса

Идея инструмента — сократить ручное копирование текстовых обозначений и координат из CAD-чертежа.

INTEROPERABILITY

Обмен через CSV

CSV служит простым промежуточным форматом для переноса данных между инженерными и офисными инструментами.
