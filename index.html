📐 AutoCAD Exporter

Экспорт координат из AutoCAD

autocad-coordinate-exporter — это утилита автоматизации для инженеров и геодезистов, предназначенная для быстрого извлечения пространственных данных (X, Y, Z) из чертежей формата DWG.

Быстрый старт

1. Загрузите LISP-скрипт coord-text-export.lsp в AutoCAD с помощью команды APPLOAD.

2. Запустите выполнение утилиты, введя в командной строке команду:

TXTCOORD

3. В открывшемся диалоговом окне выберите путь для сохранения итогового файла, после чего выделите рамкой необходимые точки на чертеже.

Техническое описание модулей программы

Для интеграции экспортера в сторонние конвейеры обработки данных (например, через Python MCP-серверы), используйте следующие ключевые методы:

Функция / Метод Тип данных Описание назначения
(get-coordinates entity) AutoLISP List Извлекает сырой ассоциативный список геометрии точки (код DXF 10) из выбранного примитива чертежа.
parse_dxf_points(file_path) Python Tuple Парсит внешний DXF/DWG файл без запуска самого AutoCAD и возвращает массив координат для ИИ-агентов.
